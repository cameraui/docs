# Mobile Apps koppeln

Die [Mobile-Apps](/de/install/mobile) verbinden sich über camera.ui Cloud mit deinem Server. Du koppelst die App einmal mit deinem Server.

## Koppeln

<Shot src="/img/remote/pairing.png" alt="Server-Kopplung mit QR-Code und Pair-Code" />

1. Öffne auf dem Server **Einstellungen → Remote Zugriff** und wähle **Server registrieren**. Ein **QR-Code**, ein **Pair-Code** und eine **Pair-URL** erscheinen.
2. Scanne den QR-Code mit der Kamera deines Handys oder öffne die Pair-URL im Browser und melde dich an deinem camera.ui-Konto an. Der Code läuft nach wenigen Minuten ab.
3. Drücke auf **Verbinden**. Der Server erscheint in deinem Konto.
4. Ist [camera.ui Cloud](/de/remote/cloud) noch aus, fragt der Server jetzt, ob er sie einschalten soll. Wähle **Aktivieren**, die Apps brauchen sie.

## Verbinden

Gekoppelte Server erscheinen in der Cloud-Server-Liste der App. Wähle einen zum Verbinden und wechsle in der App zwischen ihnen.
