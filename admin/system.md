# System & network

The **Settings → System** page (admins only) handles the server's version and a few power actions.

## Version and updates

It shows the **server** version, and the **app** version in the desktop and mobile apps. Installing updates happens on the [Updates page](/install/updating#the-updates-page); what stays here is **Manage**, which lists every published version so you can install a specific one, and **Beta updates**, the toggle at the top of the page that decides whether pre-releases are offered at all. When an installed version needs a restart to take effect, the version line shows both and offers **Restart**. See [Updating](/install/updating) for how updates work across platforms.

## Server actions

- **Restart server.** Restart camera.ui, for example after a change that needs it.
- **Reset server.** Wipe the configuration back to defaults. This removes all your settings and data and can't be undone, so it's limited to the master account.

The server also offers a **certificate** download for its HTTPS.

::: tip
Looking for the server name or network addresses? Those are under [Remote access](/remote/). Theme and language are under **Appearance**.
:::
